Change the progress note title from Compile

Three directions for the CTA and editor, each shown on the Compile screen with its default, editing, error and saved states. Reference me by id in chat — 1a, 1b, 1c.

What Classic does today
A Change Note Title button on the Finished Note screen opens a picker with three parts — Title, Subtitle and Discipline — plus a Clear Note Title action and buttons to save custom subtitles and disciplines to a personal list.
What Plus does today
The title is auto-generated from the note type and cannot be changed. On Compile it renders as a plain Progress Note label above the date, and carries unchanged to the chart note list, dashboard, print and portal.
What all three assume
Editable any time before signing, and after signing with an audit entry. Custom title and subtitle text is capped at {{ charLimit }} characters each. Clearing falls back to the note type. Every surface reads from one stored value.
